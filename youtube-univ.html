🧠 구조 요약

이 강의는 Claude Code를 처음 접하는 개발자부터 심화 자동화를 원하는 사용자까지 모두를 대상으로 한 풀버전 통합 강의다. PART 1(입문)에서는 CLAUDE.md 설정, 키보드 단축키, 슬래시 명령어, 나만의 커스텀 명령어 만들기를 다룬다. PART 2(실전)에서는 Second Brain 컨텍스트 관리, Plan Mode + TDD 기반 워크플로우, WAT 프레임워크(Workflows·Agents·Tools)를 설명한다. PART 3(심화)에서는 커스텀 스킬 제작, Sub-Agent 병렬 실행, Hooks 자동화 파이프라인, 고급 생산성 팁, 그리고 1인 개발자 풀 워크플로우 통합 데모로 마무리한다. 전체 흐름의 핵심은 Claude Code를 단순 코딩 도우미가 아닌 '에이전틱 엔지니어링' 플랫폼으로 전환하는 것이다.

📖 쉽게 풀어보기

Claude Code는 터미널에서 실행되는 AI 코딩 에이전트로, 단순히 코드를 제안하는 수준을 넘어 프로젝트 전체를 파악하고 파일을 직접 수정하며 빌드·테스트까지 수행할 수 있다.

**PART 1 — 기초 설정**: 모든 것의 출발점은 CLAUDE.md다. /init 명령으로 자동 생성되며, 글로벌(~/.claude/CLAUDE.md)과 프로젝트별(.claude/CLAUDE.md) 두 계층으로 관리된다. 여기에 절대 규칙, 아키텍처 정보, 빌드/테스트 방법, 팀 컨벤션을 적어두면 Claude가 매번 물어보지 않아도 자동으로 따른다. Shift+Tab으로 Plan 모드와 Accept 모드를 전환하고, !로 시작하면 bash 명령어를 직접 실행할 수 있다.

**PART 2 — 실전 워크플로우**: 컨텍스트 관리가 핵심이다. 'Second Brain' 개념으로 /memory에 장기 컨텍스트를 저장하고, 'Lazy Loading' 방식으로 필요한 파일만 불러온다. WAT 프레임워크는 작업을 세 층으로 나눈다: W(Workflows)는 반복 작업 흐름을 정의하고, A(Agents)는 Self-Healing 에이전트와 Sub-agent를 활용하며, T(Tools)는 원자적 도구들을 조합한다. TDD 기반 코딩에서는 에러 로그를 적극 활용하고 TODO.md로 작업 상태를 추적한다.

**PART 3 — 심화 자동화**: 커스텀 스킬은 SKILL.md를 중심으로 scripts/, references/, assets/ 폴더로 구성된다. /스킬이름으로 호출하며, 복잡한 반복 작업을 한 명령어로 자동화할 수 있다. Sub-Agent 병렬 실행은 여러 에이전트가 동시에 다른 작업을 처리하게 해 개발 속도를 크게 높인다. Hooks는 Claude가 도구를 쓰기 전(PreToolUse)·후(PostToolUse), 알림 시점(Notification), 완료 시점(Stop)에 결정론적으로 실행되는 사용자 정의 명령어다 — LLM이 선택하는 게 아니라 개발자가 미리 규칙으로 박아두는 것이 핵심 차이다.

🧩 핵심 개념

CLAUDE.md

Claude Code에게 프로젝트 규칙을 알려주는 설정 파일. 글로벌과 프로젝트별 두 계층이 있으며, /init으로 자동 생성된다. 절대 규칙·아키텍처·빌드법·컨벤션을 기록해두면 매 세션마다 다시 설명할 필요가 없다.

Plan Mode (Shift+Tab)

Claude가 실제 코드를 수정하기 전에 계획만 세우는 모드. Shift+Tab으로 Plan ↔ Accept 모드를 전환한다. 위험한 변경 전에 계획을 먼저 검토할 수 있어 실수를 줄인다.

WAT 프레임워크

Workflows(반복 작업 흐름 정의) · Agents(Self-Healing + Sub-agent 활용) · Tools(원자적 도구 조합)의 세 축으로 Claude Code 작업을 구조화하는 프레임워크.

커스텀 스킬 (Custom Skill)

SKILL.md를 진입점으로 하는 재사용 가능한 AI 작업 단위. /스킬이름으로 호출하며, 복잡한 다단계 작업을 한 명령어로 캡슐화한다. scripts/·references/·assets/ 폴더로 보조 자원을 관리한다.

Sub-Agent 병렬 실행

여러 에이전트가 동시에 독립적인 작업을 처리하는 방식. 예: 한 에이전트는 코드 작성, 다른 에이전트는 테스트, 또 다른 에이전트는 문서화를 동시에 진행한다. 컨텍스트 한계를 넘는 복잡한 작업에 특히 유용하다.

Hooks

Claude가 특정 이벤트(도구 사용 전·후, 알림, 완료 등)에 자동으로 실행하는 사용자 정의 명령어. LLM이 선택하는 게 아니라 개발자가 규칙으로 미리 정의해 결정론적으로 동작한다. 코드 포매팅 자동화, 민감 파일 보호, 커스텀 알림 등에 활용.

Second Brain / Lazy Loading

Second Brain은 /memory에 장기 컨텍스트(프로젝트 지식)를 저장해두는 방식. Lazy Loading은 모든 파일을 한꺼번에 불러오지 않고 필요할 때만 계층적으로 불러오는 컨텍스트 관리 전략.

에이전틱 엔지니어 (Agentic Engineer)

단순히 AI 도구를 쓰는 게 아니라, AI 에이전트들이 자율적으로 협업하는 시스템을 설계·관리하는 개발자 역할. 이 강의의 최종 목표.

🔗 논리 흐름

  1. Claude Code는 터미널 기반 AI 에이전트로, 단순 제안을 넘어 파일 수정·빌드·테스트까지 직접 수행한다
  2. CLAUDE.md에 프로젝트 규칙을 정의해두면 Claude가 자율적으로 컨텍스트를 이해하고 일관된 작업이 가능해진다
  3. 키보드 단축키(Shift+Tab, Escape, !)와 슬래시 명령어(/clear, /compact 등)를 숙지하면 세션 흐름을 효율적으로 제어할 수 있다
  4. Second Brain + Lazy Loading으로 컨텍스트를 체계적으로 관리하면 긴 세션에서도 품질이 유지된다
  5. WAT 프레임워크로 작업을 Workflows·Agents·Tools 세 층으로 구조화하면 복잡한 개발 과제도 체계적으로 처리된다
  6. 커스텀 스킬로 반복 작업을 캡슐화하면 한 명령어로 복잡한 다단계 작업을 자동화할 수 있다
  7. Sub-Agent 병렬 실행으로 여러 독립적 작업을 동시에 처리해 개발 속도를 획기적으로 높인다
  8. Hooks로 이벤트 기반 자동화 파이프라인을 구축하면 Claude의 모든 도구 사용에 결정론적 규칙을 강제할 수 있다
  9. 이 모든 요소를 통합하면 Claude Code를 '에이전틱 엔지니어링' 플랫폼으로 활용하는 1인 개발자 워크플로우가 완성된다

  • Sub-Agent 병렬 실행은 Claude Code를 팀처럼 운용하는 아키텍처다
